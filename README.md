# 北京 5 日行程 · 2026 国庆（3 人）

三个版本，共用同一套行程数据：

| 文件 | 用途 |
|---|---|
| `index.html` | **电脑宽屏版**。左边大地图 + 右边详情面板。直接双击打开。 |
| `mobile.html` | **安卓手机版（PWA）**。全屏地图 + 底部抽屉 + 打卡进度，可安装到主屏幕。 |
| `android/北京5日行程.apk` | **安卓 APK**。把 `mobile.html` 连同原生外壳打包，装上就能用，链接直接唤起高德和微信。 |

窄屏打开 `index.html` 时，底部会自动浮出一条提示，点「打开」即跳手机版。桌面端不显示。

## 安卓 APK

### 装到手机上

把 `android/北京5日行程.apk`（79 KB）传到手机，点开安装。首次需要允许「安装未知来源应用」。

- 包名 `com.bjtrip.app`，最低 Android 7.0（API 24），targetSdk 34。
- 自签名。装的时候系统会提示「来源未知」，正常。
- **签名密钥 `android/bjtrip.jks` 不在仓库里**（已在 `.gitignore`），只留在打包那台机器上。首次跑 `build.sh` 会自动生成一个；换台机器重新打包就是**另一个签名**，手机会拒绝覆盖安装，要先卸载旧版。想多机共用就自己把 `.jks` 拷过去。
- 网页资源（`mobile.html` 等）打在 APK 里，**不联网也能看行程**；只有地图瓦片和 Leaflet 走网络。

### 装完比 PWA 多了什么

APK 里网页和原生之间有一座桥（`AndroidBridge`）。同一份 `mobile.html` 两个环境都能跑：检测到桥就走原生，没有就退回网页方案。

| 按钮 | 浏览器 / PWA | APK 内 |
|---|---|---|
| **导航** | 开 `uri.amap.com/marker` 网页，尝试唤起高德 | 直接拉起**高德地图 App**，显示该点标注 |
| **路线** | 开 `uri.amap.com/navigation` 网页 | 直接拉起高德 App 的**路线规划**页（默认公交，起点用「我的位置」） |
| **微信** | 复制名字 + 提示 | **复制名字并打开微信**，粘进搜索框即可 |
| ✈ 去下一站 | 网页路线 | 高德 App 路线规划 |

高德的 scheme 用的是官方 URI API：标注 `androidamap://viewMap`，路线优先用现行写法 `amapuri://route/plan/`，失败再退回旧的 `androidamap://route`。坐标先做了 WGS-84 → GCJ-02 纠偏，并带 `dev=0` 告诉高德不用再偏移。

### 微信小程序：能做到什么程度

**点「微信」按钮 ≠ 直接跳进那个小程序。** 这一点得说清楚：

从第三方 App 直接打开**某个具体小程序**，官方只有两条路，都被主体资质卡死：

- 微信 OpenSDK 的 `WXLaunchMiniProgram` —— 需要在微信开放平台注册移动应用并通过**认证**（300 元，**个人主体不能认证**）。
- URL Scheme `weixin://dl/business/?...` —— 加密的那种要用目标小程序的 appid+secret 换 `access_token`，而且**非个人主体小程序才开放**；明文的那种（`?appid=&path=`）不需要密钥，但**必须由小程序方自己在 MP 后台开启开关**，第三方替不了。

故宫、国博、天安门这些小程序都不是我们的，两条路都走不通。`wx-open-launch-weapp` 开放标签只能在微信内置浏览器里用，更不行。

所以这里做的是**最接近的一步**：点一下，小程序名进剪贴板、微信同时打开，在微信顶部搜索框粘贴就行。名字都是从各景点的预约渠道里自动抠出来的（「微信小程序「故宫博物院」」→ `故宫博物院`），预约页 10 条里有 8 条能这么走。

如果哪天拿到了某个小程序的明文 scheme（需要它自己开开关），在 `P` 或 `RESV` 对应条目里加一个字段接上即可 —— 目前没接，因为拿不到。

### 自己重新打包

```bash
cd android && bash build.sh
```

不需要 Gradle / Android Studio / 任何 maven 依赖，走的是 `aapt2 → javac → d8 → zipalign → apksigner`。需要：

- JDK（`javac` / `keytool` 在 PATH 里）
- Android SDK，装 `platforms;android-34` 和 **`build-tools;36.1.0` 或更新**

`build.sh` 会自动从上一级目录收集 `mobile.html`、`manifest.webmanifest`、`sw.js`、图标打进 `assets/`，所以改完网页直接重跑脚本即可。

> ⚠️ build-tools **34.0.0 的 d8 有 bug**：javac 给匿名内部类构造函数写的 `MethodParameters` 属性里 `name_index = 0`（无名参数），d8 8.2.2 读到会抛 `NullPointerException: Cannot invoke "String.length()" because "<parameter1>" is null`。升到 36.1.0 就好了，脚本里已按 36.1.0 → 36.0.0 → 35.0.0 的顺序找。

## 手机版（mobile.html）

### 装到手机上

「添加到主屏幕」必须走 http(s)，`file://` 装不了。把这个文件夹整个传到手机能访问的地方，任选一种：

**A. 电脑起服务，手机连同一个 WiFi**（最快）

```bash
python -m http.server 8080
```

查电脑局域网 IP（Windows：`ipconfig`，看 IPv4 地址，例如 192.168.1.20），手机浏览器打开：

```
http://192.168.1.20:8080/mobile.html
```

**B. 传到任意静态托管**（Vercel / Netlify / GitHub Pages / 对象存储），把 4 个文件一起传上去：`mobile.html`、`manifest.webmanifest`、`sw.js`、`icon*.png|svg`。

打开后 Chrome 菜单 → **添加到主屏幕 / 安装应用**。装完是独立全屏 App，桌面有图标，断网也能看行程（地图瓦片除外，看过的地方会缓存）。

### 五个标签

| 标签 | 内容 |
|---|---|
| **行程** | 当天时间轴：每个事件的时刻、交通段（线路徽章 + 方向 + 站数 + 耗时 + 票价）、封站/抢票预警、景点门票与预约方式 |
| **地图** | 全屏地图，当天站点按顺序连线 |
| **预算** | 人均与总额、费用构成条形图、门票/交通明细，住宿价格可现场加减 |
| **预约** | 放票倒计时，按紧急度排序，直连官方入口 + 微信小程序搜索 |
| **更多** | 打卡总进度、12 条避坑清单、免责说明 |

### 全屏地图 + 底部抽屉

- 抽屉三档：**收起**（150px）/ **半开**（46%）/ **全开**（84%）。上下拖动把手可任意停靠，点把手在半开与收起间切换。
- 抽屉里按顺序列出当天所有站点，**点任意一行，地图飞到该站**，抽屉自动收回到最矮。
- 顶部日期筹码可左右滑动切换当天，路线与站点随之重画。

右侧三个悬浮按钮，从上到下：

| 按钮 | 作用 |
|---|---|
| ◎ 定位 | 浏览器 GPS，显示你到最近 3 个站点的实时距离 |
| ⛶ 回到路线 | 地图缩放回当天完整路线 |
| ✈ 去下一站 | 用高德打开从当前位置到当天终点的公交/地铁路线 |

触屏用双指缩放，没放 +/− 按钮（会和日期筹码打架）。

### 打卡勾选 + 进度

- 点行程项左侧圆圈即打卡，再点取消。
- 当天顶部进度条实时更新；当天全部完成显示「✓ 今天全部打卡完成」，日期筹码上也会出现 ✓。
- 记录存在浏览器 localStorage，切页、关掉重开都还在。「更多」页可一键清空。

### 锚点

`mobile.html#trip` / `#map` / `#budget` / `#resv` / `#more`，长按图标弹出的快捷方式也走这三个。

## 数据改在哪

两个 HTML 里的数据字面量完全相同，改一处记得同步另一处：

| 变量 | 内容 |
|---|---|
| `P` | 地点：名称、坐标、门票、预约方式、开放时间 |
| `DAYS` | 每天的时间轴、交通段（线路/方向/站数/耗时/票价） |
| `TICKETS` / `TRANSPORT` / `OPTIONAL` | 预算明细 |
| `RESV` | 预约项与放票时间 |
| `HOTEL` / `NIGHTS`（电脑版为 `HOTEL_DEFAULT` / `HOTEL_NIGHTS`） | 住宿单价与晚数，也可在预算页直接改 |

地铁线路颜色在 `LC`，浅色底用深色文字的线路在 `LIGHT_LINES`。

手机版的「微信」按钮没有独立字段 —— 它从 `P` / `RESV` 的 `resv`、`channel` 文本里找「小程序 / 公众号」，再用 `「」` 抠出要搜的名字（`wxTarget()`）。所以**改预约渠道文案时，把小程序名放进书名号里**，按钮就会自动跟着变。
